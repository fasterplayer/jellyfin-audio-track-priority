Audio Track Priority

When several audio tracks share the same language code, Jellyfin cannot tell them apart — a Quebec French dub and a France French dub are both just "fra". Define, per language, which track titles win. Matching is a case insensitive substring search on the audio track title. Nothing is written to your media files.

Picks the rule that matches the viewer's own "Preferred audio language" setting (Settings > Playback). Turn this off to always use the fallback language below.

Rules

Rules are matched by language. Within a rule, patterns are ordered: the first one that matches a track wins. If no pattern matches, Jellyfin's normal choice is kept. A rule with no language acts as a catch-all for every other language. Each rule can also pick a default subtitle track: reuse the same language and patterns as audio, use a different language and patterns of its own (for example, always default to English subtitles), or leave subtitle selection to Jellyfin entirely.
